# ICETTACS 2026 Conference Management System

A responsive conference management web application developed for the International Conference on Emerging Trends and Technologies in Applications of Computer Science (ICETTACS 2026).

The project is designed to provide a modern digital platform for conference management including paper submission, registration, peer review information, and conference details.

---

# Project Status

## Frontend
Frontend development is mostly completed with responsive UI design and interactive components.

## Backend
Backend development is currently in progress.

Planned backend features include:

- User authentication
- Paper submission API
- File upload system
- Database integration
- Reviewer management
- Admin dashboard
- Email notifications
